# 模様替え

部屋と家具の寸法（cm）を入れて、上から見た平面図で配置を試すツール。アカウント不要。

- スマホや他の PC からは https://pavvul.github.io/moyougae/ を開く
- 手元では `index.html` をブラウザで開く（3D 表示だけはインターネット接続が要る）
- 案はそのブラウザの中にだけ保存される。別の端末へは「ファイルに書き出す」→「ファイルを読み込む」で移す

## できること
- 家具の追加・ドラッグ・好きな角度に回す・形（四角・丸・L 字）・寸法と高さと色の変更（雛形あり）
- 重なり・はみ出し・天井より高い家具・窓をふさぐ家具の警告
- 選んだ家具から壁や他の家具までの距離（60cm 未満は赤）
- 開き戸（開く範囲を扇形で表示）・引き戸・窓
- 案の保存と切り替え、平面図の画像保存、3D 表示

## 開発
- テスト: `node test.mjs`
- 公開: `bash publish.sh`（ツールのファイルだけを gh-pages ブランチに置く）
